Animations

Animation is used to make a webpage element move, change its size, color, position, or appearance automatically over a period of time.

  • A button slowly changes color.
  • An image rotates continuously.
  • A text fades in when the page loads.
  • A box moves from left to right.

@Keyframes

def:@keyframes is a CSS rule that defines how an animation should move or change from the beginning to the end.

ex:There are 2 common ways to use @keyframes in CSS.

1.Using from and to
This is the simplest way. It defines the starting and ending states of the animation.


@keyframes animationname{
from{
property:value;
}
to {
property:value;
}
}

2. Using Percentages (0%, 50%, 100%) This method lets you define multiple steps in the animation.

@keyframes animationname{
0%{
property:value;
}
50% {
property:value;
}
100% {
property:value;
}
}
