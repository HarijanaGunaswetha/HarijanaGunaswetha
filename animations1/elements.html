PSUEDO ELEMENTS

def:Pseudo-elements are used to style a specific part of an HTML element or to add extra content without writing it in the HTML code.

Common Pseudo-elements:
::before= Adds content before an element.
::after= Adds content after an element.
::first-letter= Styles the first letter of text.
::first-line= Styles the first line of text.
::selection= Styles selected text.
::placeholder= Styles placeholder text in input fields.
